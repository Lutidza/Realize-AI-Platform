# Шапки и комментарии исходников

Источник требований —
[правило комментариев](../../../.ai/rules/development/RULE-CODE-COMMENT-DISCIPLINE.md).
Этот навык описывает применение правила и не вводит собственные исключения.

1. Прочитай правило и определи применимые файлы в границах задачи. До правки
   учитывай существующие версии и даты. При рефакторинге используй область
   компонента или модуля, установленную правилом.
2. Приведи шапки и комментарии к правилу. При необходимости открой
   [шаблон](../../../.ai/templates/code-comments/TEMPLATE-TSDOC-FILE-HEADER.md).
   Порядок обновления версии, даты и исключения бери из правила.
3. При добавлении ссылки проверь адресный документ в `documentation/**`.
   Если меняется сам контракт, подключи
   [синхронизацию документации](../../../.ai/rules/documentation/RULE-CANONICAL-DOCUMENTATION-BEFORE-CONTRACT-CHANGE.md).
   Правка оформления сама по себе не требует полного аудита документации.
4. Выполни
   [проверку комментариев](../../../.ai/checks/development/CHECK-CODE-COMMENT-DISCIPLINE.md)
   и указанную в ней команду для явного списка файлов в составе обычного
   просмотра изменений. Сообщи общий результат и
   существенные замечания без отдельного отчёта на каждый файл.
