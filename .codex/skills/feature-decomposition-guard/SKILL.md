# Структура и разделение ответственности

Источник требований —
[правило структуры кода](../../../.ai/rules/development/RULE-CODE-STRUCTURE.md).

1. Используй актуальный текст правила из контекста или дочитай недостающий
   фрагмент. Найди существующих владельцев и потребителей поведения.
   Определи разрешённую область и нужные границы файлов до реализации.
2. Выполни разделение и устранение дублирования по ответственности. Типы,
   хуки, представление и зависимости размещай по правилу; имена и комментарии
   согласуй с указанными в нём владельцами требований.
3. Проверь сохранение контрактов и работоспособность импортов. Для изменения
   публичного DTO подключи соответствующее правило, для переноса или удаления —
   правило очистки; ссылки находятся в основном правиле.
4. Выполни [проверку структуры](../../../.ai/checks/development/CHECK-CODE-STRUCTURE.md)
   в составе обычного просмотра изменений. Существенное решение и оставшиеся
   ограничения включи в общий результат.
