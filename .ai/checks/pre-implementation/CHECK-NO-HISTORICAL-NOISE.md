# Проверка исторического контекста

```yaml
check_id: CHECK-NO-HISTORICAL-NOISE
title: Проверка исторического контекста
owner_role: Владелец документации
related_rule:
  - .ai/rules/development/RULE-NO-HISTORICAL-NOISE.md
```

При review добавляемого контекста проверь его пользу для текущего назначения
файла и актуальность затронутых ссылок. Не добавляй историю диалога или отчёт
об исправлениях в active rule/code.

Пояснение причины действующего решения, migration guidance и исторический текст
в ADR/отчёте допустимы. Редакционные сомнения решай по смыслу самостоятельно;
отдельный `stop-for-approval` или отчёт на каждый фрагмент не нужен.
