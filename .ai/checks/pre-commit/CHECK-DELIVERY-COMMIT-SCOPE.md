## Критерии

Применяется внутри обработчика после staging для `commit` и `commit_push`.

- Разрешение покрывает итоговый состав; ветка и авторство определены.
- Запись использует действующую lease общего `@realize/git-runtime`.
  Настроенные hooks и подпись разработчика сохранены; служебный профиль preview
  не подменяет профиль IDE commit.
- Индекс содержит только разрешённые изменения, включая удаления. Его
  содержимое соответствует проверенной версии; новые участки просмотрены,
  неизменившиеся подтверждены без повторного вывода всего diff.
- Замена частично подготовленных версий полной рабочей версией разрешена
  только явно запрошенному полному снимку и доверенному
  `scope: { mode: "all", includePartialIndex: true }`; обычная область и
  адресные commits сохраняют запрет. Проверяются bytes индекса и рабочих файлов.
- Исключены секреты, чужие правки, случайные файлы и локальные материалы задач,
  включая `.ai-workspace/tasks/**`, логи, дампы, `node_modules` и результаты сборки.
- Необходимые проверки по связанному правилу успешны и относятся к текущим
  входам; существенные ограничения зафиксированы.
- При `REALIZE_GIT_VERIFICATION_PLAN` разрешение и selected checks проверены
  до команд; receipts получены штатным runner и повторно сверены по значимым
  входам. Результаты связаны с актуальным Git fingerprint через программный
  адаптер inspect. Неполный, изменённый или импортированный из лога receipt
  не считается успешной проверкой; широкий набор имеет конкретную причину.
  Check с `reuse: "never"` принят только из текущего запуска.
- При восстановлении сохранены прежнее назначение и исходный журнал; индекс
  доказанно принадлежит последнему принятому снимку. Новое поколение разрешено,
  связано с актуальными проверками и записано до staging; preparedTree ещё не было.
- Исходное состояние сохранено до staging; перед commit сохранены проверенное
  дерево, сообщение и авторство. Значимые входы не изменились после проверки.

Невыполненный критерий блокирует commit. БД, удалённый репозиторий и авторизация
HTTPS/SSH не входят в эту проверку.
