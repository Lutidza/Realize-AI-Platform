# CHECK-CODE-NAMING

```yaml
artifact_id: CHECK-CODE-NAMING
artifact_type: ai-development-check
owner_roles:
  - .ai/roles/developer/frontend/INDEX.md
  - .ai/roles/developer/backend/INDEX.md
owner_layer: .ai/checks/development/
rule: .ai/rules/development/RULE-CODE-NAMING.md
check_stage: development_self_review
scope: new_names_renames_and_refactoring
```

Проверяй имена в области связанного правила при обычном просмотре изменений.

- Файлы, каталоги и символы соответствуют формату и роли из правила; имена
  раскрывают фактическое назначение. Исключения имеют проверяемое основание.
- Именованные index обозначают публичные границы и имеют допустимые экспорты; импорты
  разрешаются в текущем режиме сборки или исполнения, границы client/server сохранены.
- Обязательные имена инструментов, обнаружение тестов и внешние контракты
  сохранены. Нет непредусмотренного изменения публичных ключей и маршрутов.
- При переименовании обновлены активные потребители, ссылки и шапки; результаты
  генерации получены из источников. Учтено переименование с изменением регистра.
- В согласованной области рефакторинга устранены обнаруженные нарушения.
  Если этому мешает ограничение пользователя, указан конкретный остаток;
  он не выдаётся за соответствие стандарту.

Любое невыполненное условие — замечание с конкретным файлом или символом.
Проверки импортов, типов и поведения выбираются по фактическому изменению;
полный набор тестов и отдельный отчёт для каждого имени не требуются.
