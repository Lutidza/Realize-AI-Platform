# Проверка шапок исходников

Инструмент применяет [правило комментариев](../../rules/development/RULE-CODE-COMMENT-DISCIPLINE.md)
к явному списку файлов. Работает на Node.js проекта и установленном TypeScript;
не обращается к Git, не обходит каталоги и не изменяет файлы.

```bash
npm run check:headers -- packages/payload-ai-plugin/src/integrations/runtime/GitHubConnection.service.ts package.json
```

Пути задаются от корня проекта или абсолютным путём внутри него. Повторы
объединяются; пустой список, отсутствующий файл и каталог не считаются успешной
проверкой. Вывод: `файл: нарушение` и общие количества проверенных и исключённых
файлов. Коды завершения: `0` — нарушений нет; `1` — нарушения или непроверенный
файл; `2` — неверный вызов или сбой запуска.

Проверяются единая начальная шапка, отдельные обязательные поля, точный `@file`,
числовая версия, календарная дата и непустое описание с русским текстом.
Для TS/JS используются JSDoc и синтаксический разбор TypeScript: shebang,
лицензии и директивы перед шапкой допустимы; строки и комментарии после кода
её не заменяют. Поддерживаются также блоки CSS/SCSS/JSONC, комментарии `#`
в Shell, YAML, TOML, Python, Ruby, nginx и Dockerfile, комментарии HTML/XML/SVG.
Неизвестный текстовый формат требует ручной проверки и возвращает нарушение.

Подтверждённые generated-пути, каталоги сборки и форматы исключений находятся
в [конфигурации](src/sourceHeaders.config.ts) с указанием происхождения.
Зависимости `node_modules` исключаются. Произвольный маркер `generated` в коде
и принадлежность каталогу Payload исключения не создают. Новое исключение
добавляется только с основанием по правилу; аргумента произвольного пропуска нет.

Правильность повышения версии, фактическую дату изменения, смысл описания,
качество остальных комментариев и полноту списка файлов проверяет агент.
Инструмент не восстанавливает эти сведения из истории репозитория.

Проверки самого инструмента:

```bash
node --test .ai/tools/source-headers/test/*.test.ts
node node_modules/typescript/bin/tsc -p .ai/tools/source-headers/tsconfig.json
```
