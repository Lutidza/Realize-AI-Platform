# Шаблон обязательной шапки исходника

Применимость, исключения и обновление полей задаёт
[правило комментариев](../../rules/development/RULE-CODE-COMMENT-DISCIPLINE.md).
Пример оформления для TS/JS; значения иллюстративные и не описывают текущую
версию указанного файла:

```ts
/**
 * @file packages/payload-ai-plugin/src/integrations/credentialVault.ts
 * @version 1.0.0
 * @date 2026-09-08
 * @description Шифрование и расшифровка учётных данных интеграций.
 */
```

Подставляй фактический путь, версию, дату изменения и ответственность своего
файла по правилу. Не копируй дату или версию примера автоматически.
Применимые `@docref` и `@see` добавляй после обязательных полей, только
с существующими значениями. История изменений в шаблон не добавляется.

Для другого языка используй допустимый синтаксис комментариев, сохраняя поля.
Порядок shebang, лицензии и директив инструмента определяется правилом.
