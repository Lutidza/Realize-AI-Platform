# Интеграция Ant Design Table

**Согласовано 2026-11-24. Целевой контракт.** Общий компонент использует
Ant Design Table. Шаблон задаёт тему через `ConfigProvider` и токены панели.
Модуль сущности владеет разрешёнными операциями над записями. Сервер применяет
поиск и сортировку до формирования страницы. [Контракт списка](INDEX.md#record-list-contract) · [Ant Design Table](https://ant.design/components/table/).

## Предложение к согласованию · привязка свойств таблицы

| Свойство Ant Table | Источник и поведение |
| --- | --- |
| `columns[].key`, `dataIndex` | Устойчивый `id` столбца и поле строки `field` соответственно. |
| `columns[].render` | Привязка `cell`. Код владельца маршрута разрешает идентификаторы действий и форматтеров. Сохранённый вид содержит только данные. |
| `columns[].sorter`, `sortOrder` | Для столбца с серверной сортировкой адаптер задаёт `sorter: true`. Управляемый `sortOrder` отражает активный порядок выдачи. |
| `onChange` | Выбор страницы или сортировки передаётся владельцу запроса; правила перехода описаны в настройках представления. |
| `rowKey`, `pagination.total` | Устойчивый ключ записи и общее количество записей, доступных после применения условий запроса. |

Определение ячейки принадлежит [контракту столбца](columns.md), состояние
запроса — [контракту представления](views.md). Для списка документов описаны
[целевой мобильный вид](../../realize-ai-control-panel/documents/list.md#document-list-target)
и [предлагаемые данные для адаптера](../../realize-ai-control-panel/documents/list.md#document-list-proposal).
