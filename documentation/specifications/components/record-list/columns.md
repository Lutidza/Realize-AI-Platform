# Столбцы и ячейки списка записей

## Согласовано 2026-11-24 · целевой контракт

Модуль объявляет доступные поля, действия и возможности запроса. Видимость
столбца, участие его поля в поиске и право читать поле задаются отдельно.
Для первого применения согласованы основной столбец-ссылка, дата обновления
и текстовый адрес с действием копирования. Их поведение и исходный вид
описаны в [целевом контракте списка документов](../../realize-ai-control-panel/documents/list.md#document-list-target).

## Предложение к согласованию · определение столбца

`ListColumn` описывает столбец в [определении списка](INDEX.md#record-list-contract-proposal).
Столбец имеет устойчивый `id` в рамках списка. Имена типов, полей и локальных
привязок относятся к предлагаемой схеме.

```ts
type ListCell =
  | { kind: "text"; copyActionId?: string }
  | { kind: "link"; actionId: string }
  | { kind: "date"; formatId: string };

type ListColumn<C extends string, F extends string> = {
  id: C;
  field: F;                         // поле разрешённой проекции строки
  label: string;
  role: "primary" | "secondary";
  cell: ListCell;
  sortable: boolean;
  widthBoundsPx?: { min: number; max: number };
};
```

Идентификаторы столбцов уникальны. Ровно один столбец имеет роль `primary`.
`field` выбирает поле из разрешённой проекции строки. Код маршрута разрешает
действия и форматтеры, на которые ссылается `cell`. Ограничения ширины и
доступность сортировки учитываются при проверке [настроек представления](views.md).
