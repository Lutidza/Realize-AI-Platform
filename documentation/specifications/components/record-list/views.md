# Представления и запрос списка записей

## Согласовано 2026-11-24 · целевой контракт

Администратор раздела задаёт подписи столбцов, видимость разрешённых к скрытию
полей, порядок, ширину и начальную сортировку. Пользователь меняет видимость,
порядок и ширину своих столбцов и может вернуться к виду раздела. Сортировка,
выбранная при просмотре, относится к текущей выдаче. На мобильном экране под
названием записи выводятся выбранные дополнительные поля с подписями.
[Целевой контракт списка документов](../../realize-ai-control-panel/documents/list.md#document-list-target).

## Предложение к согласованию · настройки представления

Настройки привязаны к представлению конкретного списка. Параметр `C` обозначает идентификатор
[столбца](columns.md) из [определения списка](INDEX.md#record-list-contract-proposal).

```ts
import type { elementIdentitySchema } from "@realize/element-registry";
import type { z } from "zod";

type ListSort<C extends string> = { columnId: C; direction: "asc" | "desc" };
type ColumnDisplay = { visible?: boolean; width?: number | "auto" };
type ViewLayout<C extends string> = {
  order?: C[];
  columns?: Partial<Record<C, ColumnDisplay>>;
};
type SectionView<C extends string> = ViewLayout<C> & {
  labels?: Partial<Record<C, string>>;
  defaultSort?: ListSort<C>;
};

type ViewKey = {
  screen: z.input<typeof elementIdentitySchema>;
  listId: string;
  viewId: string;
};
type StoredView<T> = { schemaVersion: "1.0"; key: ViewKey; settings: T };
type AdminView<C extends string> = StoredView<SectionView<C>>;
type PersonalView<C extends string> = StoredView<ViewLayout<C>>;
type ListQuery<C extends string> = { page: number; q?: string; sort?: ListSort<C> };
```

### Исходный вид и наследование

Базовый порядок задаёт массив определений столбцов. По умолчанию столбец виден,
его ширина автоматическая. Модуль явно задаёт исходно скрытые столбцы и
начальную сортировку.

Настройки применяются в порядке от значений модуля к общему виду раздела и
затем к персональным изменениям. Каждое свойство объединяется отдельно по ID
столбца. Пропущенное свойство наследуется, `"auto"` явно возвращает
автоматическую ширину. Указанные в `order` столбцы идут первыми, остальные
сохраняют взаимный порядок предыдущего слоя. Сброс персонального вида удаляет
только его изменения.

### Проверка сохранённого вида

Сервер проверяет `screen` через `elementIdentitySchema`, разрешает ключ
представления и определяет пользователя и область доступа раздела по сессии.
При записи он проверяет доступность ID, отсутствие повторов в порядке,
обязательную видимость основного столбца, допустимость сортировки и
положительную конечную ширину в пикселях в пределах объявленных границ.

При чтении старого вида пропускаются удалённые или недоступные столбцы и
применяются актуальные ограничения. Новые столбцы получают исходные настройки.
Изменение подписи сохраняет привязку по ID.

### Запрос и возврат к выдаче

URL задаёт страницу, поисковую строку и явную сортировку. При отсутствии
сортировки действует начальный порядок раздела. Новый поиск или смена
сортировки открывает страницу 1. Сервер разрешает сортировку только по
объявленным ключам. При возврате из записи раздел восстанавливает проверенные
параметры запроса.
