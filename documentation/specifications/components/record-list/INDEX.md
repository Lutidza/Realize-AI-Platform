# Общий список записей

**Согласовано 2026-11-24. Целевой контракт.** Общий компонент Realize использует
Ant Design Table. Первым потребителем станет список документов. Референс Task
Manager задаёт расположение инструментов, плотность строк и их визуальные состояния.

Модуль сущности объявляет доступные поля, действия и возможности запроса.
Сервер проверяет права и применяет поиск и разрешённую сортировку ко всей
доступной выборке до пагинации. Общий компонент выводит таблицу, поиск,
настройки колонок и пагинацию. Шаблон отвечает за оформление.

## Предложение к согласованию · форма определения и настроек

Предлагаемая форма `ListDefinition` связывает поля строки с определениями
столбцов, поиском и исходным видом. Имена типов, полей и локальных привязок
подлежат согласованию. `ListColumn` и `SectionView` определены в разделах
о [столбцах](columns.md) и [видах](views.md).

```ts
type ListDefinition<C extends string, F extends string> = {
  schemaVersion: "1.0";
  rowKeyField: F;
  columns: ListColumn<C, F>[];
  searchFields: F[];
  defaults: SectionView<C>;
};
```

`schemaVersion` обозначает формат сериализации. Версия компонента учитывается
в его манифесте. При отдельной поставке публичного компонента действует точная
ссылка реестра `{ identity: { namespace, id }, version }`. Реестр, редактор и
ИИ-агент читают одну схему. Доступ к записи и исполнению действий проверяет
владелец операции. [Описания для реестра и ИИ-агентов](../../realize-ai-control-panel-first-release.md#351-описания-для-реестра-и-ии-агентов).
