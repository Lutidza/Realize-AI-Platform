# Этап 0K. MCP baseline

Текущее правило: Phase 0 допускает только доказательный read-only MCP baseline.

Сделай одно из двух решений и зафиксируй ADR:

## Вариант A — официальный Payload MCP plugin

- установить совместимую официальную версию;
- зарегистрировать plugin;
- endpoint действительно существует;
- generic create/update/delete отключены;
- разрешён только минимальный read-only набор;
- API key имеет отдельную роль и минимальные права;
- endpoint не доступен анонимно;
- smoke test подтверждает tools/resources;
- `.codex/config.toml` соответствует фактическому endpoint.

## Вариант B — отложить MCP

- удалить/отключить ложную runtime-конфигурацию;
- сохранить документированный planned entry;
- не утверждать, что MCP работает;
- вернуть реализацию в Phase 1.

Предпочтение: если официальный plugin совместим и внедрение не ломает baseline, реализовать минимальный read-only endpoint. Любые MCP writes запрещены.
