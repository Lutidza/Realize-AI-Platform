# 9. Формат execution log

> **Статус: historical evidence.** Этот файл фиксирует выполненный EPIC-000
> и не является активной инструкцией. Актуальный roadmap находится в разделе
> `05-implementation-roadmap`, а порядок работ — в главе 32.

После каждого meaningful шага добавляй запись:

```markdown
## <timestamp or sequence> — <step>

### Intent
### Files touched
### Commands executed
### Result
### Evidence
### Decisions
### Risks
### Blockers
### Next step
```

Не вставляй секреты, полные токены, cookies или credential-bearing URLs.
