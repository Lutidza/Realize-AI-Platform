# 9. Формат execution log

После каждого meaningful шага добавляй запись:

```markdown
## <timestamp or sequence> — <step>

### Intent
### Files touched
### Commands executed
### Result
### Evidence
### Decisions
### Risks
### Blockers
### Next step
```

Не вставляй секреты, полные токены, cookies или credential-bearing URLs.
