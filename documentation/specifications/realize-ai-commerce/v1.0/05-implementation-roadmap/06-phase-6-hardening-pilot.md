# Phase 6. Hardening and pilot

## 6.1. Pilot

- 5–10 controlled clients;
- one vertical/standard template;
- limited tool catalog;
- agency approval for all production releases.

## 6.2. Security review

- threat model review;
- penetration testing;
- dependency audit;
- secrets audit;
- cross-installation isolation test;
- backup restore drill.

## 6.3. Operational readiness

- runbooks;
- on-call;
- support process;
- incident response;
- cost dashboards;
- capacity planning.

## 6.4. Scale gates

До 50 клиентов:

- standard onboarding;
- automated backups;
- central operator dashboard.

До 100 клиентов:

- worker autoscaling;
- release rings;
- usage reconciliation;
- error budgets.

До 1 000 клиентов:

- fleet management;
- staged rollouts;
- configuration drift detection;
- per-installation SLO;
- automated update campaigns;
- stronger self-service.
