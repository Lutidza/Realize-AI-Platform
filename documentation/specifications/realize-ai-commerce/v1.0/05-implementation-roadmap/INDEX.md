Phases показывают capability maturity, а не строго последовательные ветки:
foundation следующей фазы мог появиться раньше завершения универсальности
предыдущей. Готовность определяется exit criteria, а не номером.

Порядок следующих работ задан в [PLAT-01–PLAT-12](../06-execution-governance/32-immediate-implementation-order.md)
от 4 октября 2026 года. Он включает согласование агентского слоя,
версионирование всей платформы, измерения качества/расходов, Model Garden/Router
и обновления клиентских проектов. Статусы фаз выше не объявляют эти новые
задачи выполненными. Технический учёт расходов начинается до коммерческой Phase 5.
