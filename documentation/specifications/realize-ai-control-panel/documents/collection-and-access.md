## Коллекция и права доступа

**Первый срез реализован и проверен на отдельной БД 2026-11-22.**
Статьи внутренней документации хранятся в самостоятельной коллекции Payload
`documents` («Документы»), независимо от настроек шаблона. Политика
`adminOnly` разрешает создание, чтение, изменение и удаление только
администратору. Общий редактор, рабочие процессы (`workflow`), статусы,
черновики и публикация остаются за пределами этого среза.
[Схема коллекции](../../../../src/collections/Documents/index.ts) · [Политика adminOnly](../../../../src/access/adminOnly.ts) · [Защищённое чтение статьи](reading.md#protected-document-reading).

| Поле | Хранение и ограничения |
| --- | --- |
| `id` | Идентификатор документа, назначаемый Payload. |
| `slug` | Обязательное текстовое поле с уникальным индексом. Адрес статьи, до 128 символов. |
| `title` | Обязательный непустой заголовок, до 160 символов. |
| `description` | Необязательное поле `textarea`, до 1000 символов. |
| `sections` | Упорядоченный массив, минимум один раздел. |
| `sections[].anchor` | Явный обязательный адрес раздела, до 128 символов. Уникален внутри статьи. |
| `sections[].title` | Обязательный непустой заголовок раздела, до 160 символов. |
| `sections[].paragraphs` | Упорядоченный массив, минимум один объект `{ text }`. Обязательное поле `text` типа `textarea` содержит хотя бы один непробельный символ. |
| `updatedAt` | Дата обновления, которую ведёт Payload. |

`slug` и `anchor` состоят из групп строчных латинских букв и цифр, разделённых
одиночными дефисами. При изменении заголовка адрес сохраняется. Коллекция
отклоняет некорректные адреса и дубликаты без подбора суффикса. Раздел
получает свой адрес из `anchor`, независимо от служебного ID строки Payload.
Абзацы хранятся как обычный текст.
[Формат идентификаторов](../../../../src/collections/Documents/documentIdentifiers.ts) · [Валидаторы полей](../../../../src/collections/Documents/documentValidation.validators.ts).

### Миграция и проверка на отдельной БД

Источником схемы служит конфигурация коллекции. Миграции, включая SQL,
TypeScript, snapshot и индекс, создаёт генератор Payload/Drizzle. Типы Payload
также обновляются штатным генератором.

22 ноября 2026 года на отдельном PostgreSQL прошли 35 миграций.
Цикл `down` и `up` для пустой коллекции `documents` сохранил трёх ранее
созданных тестовых пользователей. Администратор создал и обновил статью через
Payload API. Повторный `slug` и повторный `anchor` в одной статье вернули
HTTP 400. Для гостя и пользователя с ролью `customer` каждая из четырёх
операций API вернула HTTP 403.
[Результаты проверки коллекции и чтения](../../../../.ai-workspace/tasks/2026-11-11-control-panel-first-slice/logs/documents-db-20261122/result-707a063fbc0d13c2.json).

## Доступ к списку документов

Маршрут `/system/documents` проверяет административную cookie-сессию через
`requireSystemAdmin`. Сервер читает `documents` через Payload Local API от
имени текущего администратора с `overrideAccess: false` и `depth: 0`.
Коллекция применяет свою политику доступа к выборке. [Проверка сессии](../../../../src/components/admin/documents/readDocumentsBrowserActor.service.ts) · [Выборка списка](../../../../src/components/admin/documents/readDocumentList.service.ts).

22 ноября 2026 года в изолированной среде проверены маршруты списка
`/system/documents` и чтения `/system/documents/[slug]`. Гостю, пользователю
`customer` и запросу только с bearer-токеном отказано на обоих маршрутах.
Для гостя и `customer` API коллекции вернул HTTP 403.
[Результаты проверки доступа](../../../../.ai-workspace/tasks/2026-11-11-control-panel-first-slice/logs/documents-list-db-20261122/result-6869e1012b26dceb.json).
