# Создание статьи внутренней документации

<a id="document-article-creation"></a>

## Форма «Создать статью»

**Реализовано и проверено в изолированной среде 2026-11-24.** Действие
«Создать статью» рядом с заголовком списка открывает защищённый маршрут
`/system/documents/actions/create`. Форма занимает `panel-content` в макетах
`default` и `without-topbar`. Параметр `fromPage` хранит номер исходной
страницы списка. При прямом входе используется первая страница. Вложенный
путь формы сохраняет адреса статей с одноуровневыми `slug`, включая `create`
и `actions`. [Маршрут формы](<../../../../src/app/(system-admin)/system/documents/actions/create/page.tsx>) · [Геометрия экранов документов](../shell/content-grid.md#document-screen-geometry).

### Поля и адреса

| Поле | Контракт формы |
| --- | --- |
| Заголовок статьи | Обязательный, до 160 символов. |
| Адрес статьи (`slug`) | Обязательный, до 128 символов. Уникален в коллекции `documents`. |
| Краткое описание | Необязательное, до 1000 символов. |
| Разделы | Минимум один. Для каждого обязательны заголовок до 160 символов, адрес `anchor` и хотя бы один непустой текстовый абзац. |

В новой форме один пустой раздел с одним абзацем. Администратор может
добавлять разделы и абзацы и менять их порядок.
[Компонент формы](../../../../src/components/admin/documents/ArticleCreateForm.component.tsx).

Форма предлагает `slug` по заголовку статьи и `anchor` по заголовку раздела.
Она транслитерирует кириллицу, переводит латиницу в нижний регистр и
разделяет группы букв и цифр одиночными дефисами. Оба адреса ограничены
128 символами. Каждый `anchor` уникален внутри своей статьи. Например,
первый раздел может открываться по адресу
`/system/documents/kak-nastroit-maket#pervyi-zapusk`.
Пока администратор не отредактировал адрес вручную, предложение обновляется
вместе с заголовком. После ручной правки форма сохраняет выбранное значение.
При последующем изменении заголовка сохранённой статьи или раздела адрес
остаётся прежним. [Формирование адресов](../../../../src/components/admin/documents/suggestDocumentIdentifier.util.ts) · [Правила коллекции](collection-and-access.md#document-collection-contract).

### Сохранение и отмена

При отправке форма проверяет поля и блокирует повторное сохранение. Сервер
проверяет административную cookie-сессию, повторяет валидацию и создаёт
статью от имени текущего пользователя через Payload с `overrideAccess: false`.
Права проверяет коллекция. Уникальный индекс `slug` действует и при двух
одновременных запросах. [Валидатор формы](../../../../src/components/admin/documents/documentArticleInput.validator.ts) · [Серверные действия](../../../../src/components/admin/documents/createDocumentArticle.action.ts).

После успешного сохранения открывается созданная статья с текущими `mode`,
`layout` и исходным `fromPage`. Ссылка «Все документы» над статьёй возвращает
на ту страницу списка, с которой открыли форму.
[Защищённое чтение статьи](reading.md#protected-document-reading).

«Отмена» в пустой форме сразу возвращает к исходной странице списка,
сохраняя текущие тему и макет. В изменённой форме «Продолжить редактирование»
оставляет черновик открытым, а «Выйти без сохранения» возвращает к списку.
[Адреса и возврат к списку](list.md#адреса-и-возврат-к-списку).

### Ошибки и проверка результата записи

Форма показывает ошибку у соответствующего поля и переводит фокус на первое
поле с ошибкой. Это относится и к занятому `slug`, и к повторному `anchor`
внутри статьи. Введённые значения и порядок разделов и абзацев сохраняются
при исправлении ошибок и переключении макета.

Если ответ на сохранение потерян и результат записи неизвестен, форма
удерживает отправленный черновик и блокирует повторную отправку.
Действие «Проверить сохранение» передаёт серверу только `slug`. После
проверки доступа сервер ищет статью, а форма сравнивает найденное содержимое
с отправленными данными, включая порядок разделов и абзацев.

| Результат проверки | Действие формы |
| --- | --- |
| Сохранённая статья совпадает с отправленными данными | Открывает статью для чтения. |
| Статья отсутствует | Разрешает исправить данные или повторить сохранение. |
| По адресу сохранено другое содержимое | Показывает ошибку у поля адреса и предлагает изменить `slug`. |
| Проверка недоступна или утрачена сессия администратора | Сообщает причину и оставляет возможность повторить проверку. |

[Обработка действий формы](../../../../src/components/admin/documents/useArticleCreateForm.hook.ts) · [Сверка сохранённой статьи с черновиком](../../../../src/components/admin/documents/matchesSubmittedDocumentArticle.util.ts).
